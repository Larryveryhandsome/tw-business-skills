# 不動產 A4 單據包

> **免責**：所有單據都是「範本」，不是法律文件定稿，也不是法律意見。正式簽署前請送律師或代書審閱。
> 法規基準日：2026-10-24。費率、押金上限、報酬上限等數字**不內建**，請填 `brand.toml` 的 `[fees]` 並核對現行法規。

## 共用規則
- **抬頭、統編、費率、品牌色、表單編號全部放設定檔**（`config/brand.example.toml` 的 `[letterhead]`／`[fees]`），範例用虛構資料。
- 輸出 A4 PDF；**列印前確認頁數**（單頁單據必須只有一頁）。
- 簽章欄左右並排，大小章用印框要留位置。
- 每份結尾固定一行：「本文件為範本，正式簽署前請送法務或代書審閱。」
- PDF 做法：HTML → Chrome／Edge headless 列印（`--headless=new`，背景執行不跳視窗）；中文字體約 10.5pt、邊界約 12mm。

## 小工具：斡旋金簽收單
```
python scripts/make_receipt.py --brand ../../config/brand.example.toml --data scripts/receipt.example.toml --out receipt.html --pdf receipt.pdf
```
- 金額自動產生國字大寫並與阿拉伯數字一起列出，避免大小寫不一致。
- 加 `--pdf` 會用本機 Chrome／Edge 列印並驗證只有 1 頁（可用環境變數 `CHROME_PATH` 指定）。

## 1. 斡旋金簽收單
- 輸入：案名、地號（可多筆合併成表）、單價、金額、日期、斡旋有效期間。
- 版面：物件與地號表 → 斡旋條件表 → 要約書告知 → 買方與收受人簽章並排。
- **要約書告知**：建議在收斡旋金前以書面說明買方可改用主管機關公告的要約書，並加註「買方已知悉並自願選擇斡旋金」。原則上，未說明可能引發公平交易法 §25（概括條款）的爭議；該條條文本身未提及要約書，實際見解請問律師。
- 斡旋金與定金的法律性質、是否因屋主簽收而轉為定金，**實務見解不一，請交律師判斷**（定金效果見民法 §249）。
- 山坡地／農地等限制可加告知條款。

## 2. 委託銷售補充協議（既有客戶免服務費）
- 常見四條款：①既有客戶附表（含配偶、直系親屬、實質控制法人）②對附表客戶免收服務費 ③協助事項另議計費 ④與原委託牴觸時的優先順序。
- 流程：填甲乙方與標的 → 附表 → 條款 → 用印框 → PDF → 送審。

## 3. 租賃簽約確認表（六段式）
1. 人與權利（身分、產權、委託授權）
2. 條款（租期、租金、押金、修繕、轉租）
3. 屋況
4. 用印
5. 款項
6. 交屋
- 加「暫停簽約」紅框（任一關鍵項未過就停）。
- 自動檢核欄位的上限數字（押金月數、仲介報酬月數）**讀自 `brand.toml` 的 `[fees]`**；範例檔刻意留空或標「待核對」，請對照現行《租賃住宅市場發展及管理條例》與《不動產經紀業報酬計收標準》自行填入。
- 三方簽章；列印版去掉互動元件。

## 4. 點交確認書（買賣／租賃共用）
鑰匙、讀表（水電瓦斯）、費用結清、設備清單、瑕疵紀錄、雙方簽章與日期。

## 5. 宿舍公約與借款小契約（僅提供檢核重點，牽涉勞動關係，務必交專業人士）
- 宿舍公約：先問費用、配置、重點規則；建議含「非租賃定性」說明、薪資扣抵須勞工書面同意（見 `tw-labor-compliance-check`）、最終解釋與事實認定條款。
- 借款契約：先指出範本內部矛盾，再問還款方式、利率、交付方式；寫清本金、年利率、期數、逾期利息（不超過法定上限）、期限利益喪失、現金簽收欄與還款紀錄表。

## 流程
1. 問最少必要資料（缺項一次問完）。
2. 套版產出 HTML。
3. 轉 PDF，數頁數、檢查簽章欄不被切斷。
4. 回報：檔案路徑、頁數、待使用者確認的欄位。

## 常見坑
- 範本互相矛盾（利率與逾期利息、期數與總額）沒先指出就直接生成。
- 版型把店名、證號寫死。
- 簽章欄跨頁。
- 大寫金額與小寫不一致，一定自動產生並核對。
